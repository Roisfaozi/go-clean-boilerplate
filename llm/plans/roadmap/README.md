# Roadmap Plans

## Purpose

Folder ini untuk plan multi-tahap yang lintas modul, lintas app, atau lintas milestone.

Dokumen di sini harus tetap berguna walau implementasi dilakukan bertahap dalam banyak sesi.

## Cocok Untuk

- penyelarasan kontrak API lintas `apps/web`, `apps/client`, dan backend
- rollout observability, tracing, metrics, atau logging improvement
- stabilisasi worker, webhook, audit, dan async side effects
- re-architecture frontend design system atau shared package boundary

## Isi Yang Disarankan

- current state summary
- target state
- fase rollout
- dependency antar fase
- migration or compatibility concern
- verification and rollback thinking

## Bukan Untuk

- catatan audit sementara
- patch kecil satu module
- recommendation backlog tanpa jalur eksekusi jelas
