# Plans

Gunakan folder ini untuk rencana implementasi besar atau staged roadmap yang lebih durable dari `llm/tasks/todo.md`.

## Subfolder

- `improve/` untuk plan peningkatan bertahap
- `roadmap/` untuk roadmap lintas milestone atau lintas modul

## Jangan simpan di sini

- state kerja aktif harian; pakai `llm/tasks/todo.md`
- fakta stabil repo; pakai `llm/cache/`
- rekomendasi non-urgent tanpa plan eksekusi; pakai `llm/recommendations/`
